# Mood and skill XP

The Needs panel shows the current mood and its effect. The game checks mood when a skill earns XP. For example, driving 250 clean metres earns one base XP. Twenty such awards give 23 XP while Content or 17 XP while Tense.

| Mood | Skill XP per 100 base XP |
| --- | --- |
| Content | 115 |
| Okay | 100 |
| Tired, Hungry, Bored or Tense | 85 |
| Lonely | 150 Charisma, 85 in each other skill |

Each skill keeps its own fractional XP until it reaches a whole point. The fraction survives mood changes and clears at the level cap or when the page reloads. Only whole points enter the save and cloud progress. Credit rewards and existing level perks keep using the earned skill level.
