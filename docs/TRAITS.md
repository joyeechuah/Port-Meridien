# Traits

Open Pause → Skills → Traits, select up to two buttons and choose Apply traits. Closing the panel discards the draft. Applying a different selection uses the change for that UTC day. Clearing both traits is a change. Keyboard users can Tab between buttons and use Enter or Space. On a controller use the D-pad, A to select and B to close Skills.

| Trait | Effect |
| --- | --- |
| Foodie | Cooking XP +25%. Hunger falls 15% faster. |
| Gearhead | Driving XP +25%. Roadside repairs cost 10% less after the Handiness discount. |
| Athletic | Fitness XP +25%. Energy falls 10% slower on foot. |
| Outgoing | Charisma XP +25%. Social falls 15% faster. |
| Homebody | REST, SNACK and PLAY restore 20% more at home. Fun falls 10% faster in active play away from home. |
| Shutterbug | Photography XP +25%. The first six photos per UTC day earn XP. |
| Handy | Handiness XP +25%. Home snacks award double base Cooking XP. |
| Free spirit | Wants pay 20% more. Two rerolls per UTC day. |

Mood and skill trait bonuses multiply. Content with Foodie earns 575 Cooking XP per 400 base XP. Each skill carries units of 1/400 XP until a whole point can be awarded. Reloading clears fractional carry.

Traits affect progression, so a committed choice and its change day travel with the selected cloud save. An untouched empty selection matches older saves. Clearing a selection retains the day so a restore preserves the editing limit. A used second reroll is saved with the wants and a sixth photo with the daily counter.
